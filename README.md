# LivingShopkeeper

LivingShopkeeper is a packet-NPC system for voiced characters, dialog menus, lobby NPCs, barkers, and
player-owned chest-backed shops.

Start with the [complete usage guide](GUIDE.md). It includes installation, commands, file layout, dialog and
voice authoring, shop setup, barker/lobby configuration, troubleshooting, and 20 working examples.

For a large copyable character with branching conversation, all dialog conditions, contextual place talk,
combat reactions, and a voice-clip inventory, see the [Mira full showcase](SHOWCASE.md).
